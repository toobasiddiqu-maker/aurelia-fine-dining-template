# AURELIA — Luxury Fine Dining Website Template

A premium, sellable HTML website template for fine-dining restaurants in the USA & UK.
Demo brand: **AURELIA — Mayfair & Manhattan** (fictional; replace with your own name, logo, photos and text).

## What's inside
- Full-screen hero with Reserve / View Menu calls to action
- Press & awards strip (placeholder quotes)
- Chef story with portrait and signature
- Signature dishes gallery with prices
- Interactive tasting menu — Starters / Mains / Desserts / Wine tabs
  - Calories per dish (USA style) and allergen notes (UK style)
  - Working **$ USD / £ GBP toggle** that converts every price on the page
- Private dining & events with room capacities and an enquiry form
- Gift cards with live amount preview
- Guest testimonials slider
- Two locations & hours — New York and London
- Reservation form with OpenTable / Resy / Tock placeholder buttons
- Newsletter signup and full footer

## Design
Dark charcoal `#121212`, muted gold `#C6A15B`, cream `#F5EFE6`. Elegant serif display
headings, clean sans body, subtle scroll animations, fully responsive / mobile-first.

## How to customise (buyer guide)
1. Open `index.html` and search for the demo brand name **AURELIA** — replace it with yours everywhere.
2. Replace the demo dish names, descriptions, calories, allergens and prices in the menu section.
   Prices carry a `data-usd` value; the £ price is calculated automatically by the toggle.
3. Swap the placeholder photos for your own food / interior photography (same file names = no code changes).
4. Point the OpenTable / Resy / Tock buttons to your own booking links.
5. Update locations, hours, phone and email in the Locations and Footer sections.
